# MyLauncher Adminpanel

Веб-панель администратора для управления сборками Minecraft в собственном репозитории MyLauncher. Она позволяет создавать пакеты и версии, загружать файлы, проверять манифесты и управлять публикацией.

## Роль в проекте

Adminpanel — статическое приложение без отдельного frontend-сборщика: `index.html`, `app.js`, CSS и шрифты. Его раздаёт Python backend из соседнего каталога `MC-launcher-server` по корневому пути `/`. Браузер и API работают с одного origin; отдельные Node.js зависимости, CORS и frontend-сервер не нужны.

```text
Браузер администратора
        | HTTPS
Reverse proxy (например, Caddy)
        |
MC-launcher-server :8787
        |-- /             -> эта панель
        |-- /api/admin/*  -> административный API
        `-- /api/*        -> публичный каталог и файлы
```

## Возможности

- Вход по паролю администратора и защищённая сессия.
- Обзор сборок, опубликованных версий, черновиков, скачиваний и последних действий.
- Поиск и фильтрация релизов, просмотр журнала административных операций.
- Создание и редактирование пакетов и черновиков с метаданными Minecraft, загрузчиком, версией Java, каналом и игровыми настройками.
- Загрузка отдельных файлов или папки с подпапками, выбор назначения, просмотр очереди и отмена загрузки.
- Выбор официальных версий Minecraft и совместимых версий loader из API репозитория.
- Валидация готовности, публикация и снятие публикации, клонирование и архивирование версий.
- Светлая и тёмная темы, адаптивная раскладка.

Доступность серверных операций зависит от версии backend. Панель сообщает об устаревших или неподдерживаемых API; обновляйте её и `MC-launcher-server` как единый комплект.

## Требования

- Запущенный `MC-launcher-server` с доступной конфигурацией и каталогом данных.
- Современный браузер с JavaScript и поддержкой загрузки файлов.
- HTTPS при доступе через интернет. Для локальной разработки можно использовать loopback HTTP.

## Запуск

Из корня репозитория откройте PowerShell:

```powershell
cd .\Server\MC-launcher-server
py -3.12 .\start_local.py
```

При первом запуске задайте пароль администратора. После старта откройте `http://127.0.0.1:8787/`. Для повторного запуска после первичной настройки:

```powershell
py -3.12 .\server.py
```

Не открывайте `index.html` напрямую и не запускайте панель через произвольный static server: в этом случае ожидаемые same-origin `/api/...` endpoints не будут доступны. Подробная настройка backend, HTTPS reverse proxy и Windows-службы описана в [README сервера](../MC-launcher-server/README.md).

## Рабочий процесс релиза

1. Создайте пакет либо выберите существующий.
2. Создайте черновик версии, задайте SemVer-версию, Minecraft, loader и канал.
3. Добавьте файлы и игровые настройки. Файлы загружаются в хранилище сервера и включаются в манифест.
4. Запустите проверку готовности и исправьте найденные ошибки.
5. Опубликуйте проверенную версию. Опубликованный манифест неизменяем; чтобы изменить его, снимите публикацию и верните версию в черновик.

Канал `beta` предназначен для предварительных публичных сборок, а не для приватной раздачи. Контрольные суммы помогают обнаружить повреждение или подмену при передаче, но не гарантируют безопасность модов и других исполняемых файлов.

## Файлы интерфейса

- `index.html` — структура экранов, формы, диалоги и доступные элементы.
- `app.js` — состояние интерфейса, авторизация, запросы API, загрузки и операции с релизами.
- `theme.css` — базовая тема, типографика и общие компоненты.
- `browser.css` — обзор, навигация, таблицы и журнал действий.
- `pack.css` — создание и редактирование сборок.
- `upload.css` — область загрузки и очередь файлов.
- `icons.svg`, `Manrope-VF.ttf`, `DMMono-Regular.ttf` — иконки и шрифты.
