# MyLauncher

MyLauncher — локальный лаунчер Minecraft для Windows на Tauri 2, React и TypeScript. Он управляет игровыми инстансами, аккаунтами и локальными Minecraft-серверами; загрузки и настройки хранятся на устройстве.

## Возможности

- Создание, изменение, дублирование и удаление игровых инстансов с отдельными версиями Minecraft и загрузчиками Vanilla, Fabric, Forge и NeoForge.
- Загрузка клиента Minecraft, библиотек, ресурсов и natives с проверкой SHA-1; проверка и восстановление игровых файлов.
- Автоматическая установка подходящей версии Java Temurin при первом запуске. Для инстанса можно настроить объём памяти, JVM-флаги, разрешение окна и полноэкранный режим.
- Запуск и остановка игры с выводом логов в приложении. Одновременно лаунчер запускает одну игру; запущенный инстанс нельзя изменить или удалить.
- Каталог Modrinth для модов, ресурс-паков, шейдеров и датапаков. Для модов доступны зависимости, обновление, включение и отключение; датапаки устанавливаются в выбранный мир.
- Каталог сборок Modrinth с фильтрами Minecraft/loader, выбором версии `.mrpack`, индикатором прогресса и отменой установки. Манифест проверяется до создания инстанса; загрузки сверяются по SHA-1/SHA-512 и размеру, пути и overrides валидируются, а при ошибке незавершённый инстанс удаляется. Поддерживаются Vanilla, Fabric, Forge и NeoForge; Quilt и неизвестные loaders пока не поддерживаются.
- Собственный HTTPS-каталог сборок рядом с Modrinth. Лаунчер получает опубликованные стабильные версии, создает временный инстанс, устанавливает Minecraft/loader/Java, скачивает только контент и проверяет каждый размер и SHA-256. Отмена/ошибка удаляет временный инстанс. Для установленных сборок доступна проверка обновлений: изменённые файлы переключаются с резервированием, пользовательские файлы вне манифеста сохраняются. Настройки и версия репозитория хранятся в метаданных инстанса.
- Раздел инстанса с установленными модами, файлами, мирами и логами.
- Offline-профили и вход через Microsoft Device Code Flow с проверкой Xbox/XSTS и лицензии Minecraft Java Edition.
- Установка и управление локальными серверами Vanilla, Paper, Purpur, Fabric, Forge и NeoForge. Доступность ядер и версий зависит от выбранной версии Minecraft и ответов их публичных API. В приложении доступны консоль, команды, статус, метрики процесса и управление контентом Modrinth.
- Светлая и тёмная темы, пользовательские цвета интерфейса.

## Требования

- Windows 10 или 11
- Node.js и npm
- Rust toolchain
- Microsoft C++ Build Tools
- WebView2 Runtime

Для загрузки игры, Java, контента и серверных ядер требуется подключение к интернету. Установка серверов поддерживается начиная с Minecraft 1.5.2; NeoForge требует Minecraft 1.20.1 или новее. Перед установкой сервера необходимо принять Minecraft EULA.

## Разработка

Сервер репозитория и web-панель администратора находятся в [`Server/MC-launcher-server`](../../Server/MC-launcher-server/README.md) и [`Server/MC-launcher-adminpanel`](../../Server/MC-launcher-adminpanel/README.md). Общая карта проекта находится в [главном README](../../README.md); архитектура API, формат манифеста, Windows deployment и backup описаны в README сервера.

```powershell
npm install
npm run tauri dev
```

Собрать frontend и проверить TypeScript:

```powershell
npm run build
```

Проверить типы без сборки, выполнить frontend-тесты и lint:

```powershell
npm run typecheck
npm run test
npm run lint
```

Запустить тесты Rust:

```powershell
cargo test --manifest-path src-tauri/Cargo.toml
```

Собрать Windows-приложение и установщики:

```powershell
npm run tauri build
```

Скрипт сборки Tauri запускает `npm run build`. Установщики MSI и NSIS размещаются в `src-tauri/target/release/bundle/msi` и `src-tauri/target/release/bundle/nsis`.

## Вход через Microsoft

Для Microsoft-аккаунта настройте публичное приложение в Microsoft Entra:

1. Разрешите вход с personal Microsoft accounts.
2. Включите public client flow и Device Code Flow.
3. Запрашивайте scopes `XboxLive.signin` и `offline_access`.
4. Не создавайте и не встраивайте client secret.

Укажите Client ID приложения в разделе «Аккаунты» и следуйте инструкциям входа. Для запуска Minecraft Java Edition аккаунту нужна соответствующая лицензия. Refresh token хранится в Windows Credential Manager. Краткоживущий access token передаётся запущенной JVM Minecraft в аргументах процесса; локальные программы, имеющие право просматривать процессы пользователя, могут его увидеть. Не запускайте лаунчер вместе с недоверенным ПО.

Offline-профиль создаётся локально и не проходит аутентификацию Microsoft, Xbox или Minecraft. Он не подходит для серверов, требующих официальной онлайн-аутентификации.

## Доверие к источникам

Собственный репозиторий является доверенной границей: его владелец может устанавливать и заменять файлы сборки, а также задавать JVM-параметры. Лаунчер требует явного согласия перед установкой, но манифесты репозитория не подписываются криптографически; подключайте только серверы, которыми управляете или которым доверяете.

Установщики Forge и NeoForge выполняют код из загруженных installer-пакетов. Лаунчер ограничивает время их работы и проверяет Maven SHA-1 sidecar, когда upstream его публикует, но не проверяет цифровую подпись installer-кода. Paper проверяется по SHA-256, Vanilla — по SHA-1. Purpur публикует только MD5: он выявляет случайное повреждение, но не защищает от целенаправленной подмены. Fabric Meta не предоставляет checksum для серверного JAR; для него остаётся доверие к HTTPS и разрешённому upstream-домену.

SQL plugin удалён. Renderer обращается к базе через backend-команды с точным allowlist статических prepared queries; произвольные SELECT, DDL, multi-statement запросы и SQL plugin capabilities не доступны. При XSS остаются разрешённые CRUD-операции приложения, поэтому renderer не следует считать доверенной границей. Инициализация сбрасывает отклонённый promise для повторной попытки. Миграция схемы выполняется в backend SQLite-транзакции; перенос legacy-аватаров остаётся повторяемой data migration, поскольку файловые операции нельзя включить в транзакцию базы.

## Данные приложения

Локальные данные находятся в `%APPDATA%\MyLauncher`:

- `launcher.db` — SQLite-база настроек, аккаунтов и инстансов.
- `instances` — файлы игровых инстансов.
- `servers` — установленные серверы.
- `java`, `assets`, `libraries` — Java Temurin и общие файлы Minecraft.
- `logs` — логи лаунчера.

Папку можно открыть из раздела «Настройки». Удаление этих данных вручную может удалить игровые файлы, сохранения и настройки.
